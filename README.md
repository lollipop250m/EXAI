# EXAI Web MVP V1

Πρώτο κομμάτι: οποιαδήποτε συσκευή με browser -> paste conversation -> editable .docx.

Δεν υπάρχει backend και δεν υπάρχει login στην V1. Η δημιουργία του Word γίνεται τοπικά στον browser.

Άνοιξε το index.html σε browser και κάνε paste μια συνομιλία με κενές γραμμές ανάμεσα στα μηνύματα.
